# Strategi bisnis & conversion architecture

Konsep baru: **THE ART OF STAYING** — *usulan kreatif*, bukan tagline resmi Ashavin. Narasi: ruang yang bisa didatangi kapan saja untuk kopi, pekerjaan, obrolan, dan acara privat.

1. User dari pencarian lokal → halaman lokasi dengan map, 24 jam, dan CTA arah.
2. User dari IG → galeri/ruang/VIP → form enquiry WhatsApp.
3. User ingin makanan → menu filter/search → tanya harga terbaru atau cek mitra.
4. User komunitas → halaman Community/Event → CTA kerja sama.

CTA utama = Jelajahi Menu, Petunjuk Arah, Tanya/Reservasi VIP. Tidak menawarkan ketersediaan palsu. Event dan foto asli bergantung konfirmasi owner. Pengukuran conversion belum aktif sampai consent dan analytics benar-benar dikonfigurasi.
