# Ashavin Coffee Space — V5 Luxury Editorial Refresh

Date: 2026-10-28. Version: V5 (presentation/staging build).

## Implemented changes

1. Removed the requested presentation-only disclaimer and large menu note text throughout the HTML pages; preserved accurate, smaller contextual information where relevant.
2. Elevated the art direction to cinematic, dark-espresso luxury hospitality with refined typography, copper/gold hairlines, photographic storytelling, soft imagery contrast, editorial whitespace, and restrained hover states.
3. Generated eight new photorealistic demo assets: daytime coffee bar, daytime lounge, evening coffee bar, private lounge, iced coffee, matcha, rice plate, and mixed platter. Added a four-photo editorial story chapter on the homepage. Updated product-category and room imagery and the gallery.
4. Refined two persistent floating actions at the lower-right corner on desktop and mobile: Order opens `order.html`, WhatsApp opens a prefilled message via `wa.me` using verified configuration. Both use the same design language.
5. Implemented motion polish: a thin scroll progress indicator, restrained hero scroll scaling on desktop, staged photo reveals, image hover feedback, and respect for reduced-motion settings.
6. Removed tap highlight and touch-callout behavior from interactive controls/decorative imagery, while keeping text selectable, native form editing, screen reader labels, and keyboard focus rings.
7. Updated page image alt/captions to identify demo visuals as illustrations rather than real Ashavin photography.

## Known constraints / content integrity

- Generated demo photos are visual illustrations of an upscale café and typical products. They do **not** show the actual Ashavin site, VIP room or the specific named menu items.
- Existing product prices are transcribed from supplied menu artwork, not independently reconfirmed by cafe ownership. They can change.
- Existing brand/promotional assets outside the new gallery remain in the project for owner-approved reuse if needed. Some third-party/official source media may require usage permission before public commercial rollout.
- Google Maps, WhatsApp, Instagram, and delivery marketplaces require their respective online platforms. The website does not fake completed orders or bookings.
- Performance and accessibility certification, genuine production-site smoke tests, owner approvals, and browser integration tests using public networks remain pending.
